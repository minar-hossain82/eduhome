# 🎓 EduHome – Online Education Landing Page

EduHome is a modern and responsive education landing page designed to showcase online courses, expert instructors, educational events, and learning opportunities. The website focuses on delivering an engaging learning experience through a clean UI, responsive layout, and user-friendly design.

## 🌐 Live Demo

🔗 https://minar-eduhome.vercel.app/

## 📂 GitHub Repository

🔗 https://github.com/minar-hossain82/eduhome

## ✨ Features

- 🎓 Modern education landing page
- 📱 Fully responsive design
- 📚 Course showcase section
- 👨‍🏫 Expert instructors section
- 🏫 About educational platform
- 📅 Upcoming events section
- 📩 Newsletter subscription
- 🎯 Call-to-action section
- ⚡ Smooth user experience
